# Visual Studio Code

| Azione | Shortcut |
|---|---|
| Apri palette comandi | `Ctrl+Shift+P` |
| Apri file rapidamente | `Ctrl+P` |
| Mostra/nascondi terminale | `Ctrl+ò` |
| Sposta riga su/giù | `Alt+↑` / `Alt+↓` |
| Duplica riga | `Shift+Alt+↓` |
| Commenta riga | `Ctrl+/` |
| Formatta documento | `Shift+Alt+F` |
| Rinomina simbolo | `F2` |
| Vai alla definizione | `F12` |
| Trova e sostituisci | `Ctrl+H` |
| Multi-cursore sulla selezione | `Ctrl+Shift+L` |
| Chiudi tab | `Ctrl+W` |
