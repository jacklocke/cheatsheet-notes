# Windows Terminal

| Azione | Shortcut |
|---|---|
| Nuova scheda | `Ctrl+Shift+T` |
| Chiudi scheda / pannello | `Ctrl+Shift+W` |
| Scheda successiva / precedente | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Dividi orizzontale | `Alt+Shift+-` |
| Dividi verticale | `Alt+Shift++` |
| Sposta focus tra pannelli | `Alt+Frecce` |
| Palette comandi | `Ctrl+Shift+P` |
| Cerca nel buffer | `Ctrl+Shift+F` |
| Copia / incolla | `Ctrl+Shift+C` / `Ctrl+Shift+V` |
| Impostazioni | `Ctrl+,` |
