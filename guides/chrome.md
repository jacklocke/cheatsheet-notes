# Google Chrome

| Azione | Shortcut |
|---|---|
| Nuova scheda | `Ctrl+T` |
| Chiudi scheda | `Ctrl+W` |
| Riapri scheda chiusa | `Ctrl+Shift+T` |
| Vai alla barra indirizzi | `Ctrl+L` |
| Cerca nella pagina | `Ctrl+F` |
| Ricarica (forzata) | `Ctrl+Shift+R` |
| Strumenti sviluppatore | `F12` |
| Scheda successiva / precedente | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Gestione finestra incognito | `Ctrl+Shift+N` |
| Cronologia | `Ctrl+H` |
| Segnalibri | `Ctrl+D` |
