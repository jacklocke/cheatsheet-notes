# Notepad++

| Azione | Shortcut |
|---|---|
| Nuovo / apri / salva | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` |
| Salva tutto | `Ctrl+Shift+S` |
| Chiudi scheda | `Ctrl+W` |
| Trova / sostituisci | `Ctrl+F` / `Ctrl+H` |
| Trova nei file | `Ctrl+Shift+F` |
| Vai alla riga | `Ctrl+G` |
| Duplica riga | `Ctrl+D` |
| Elimina riga | `Ctrl+L` |
| Sposta riga su / giù | `Ctrl+Shift+↑` / `Ctrl+Shift+↓` |
| Commento riga | `Ctrl+Q` |
| Scheda successiva | `Ctrl+Tab` |
