# VS Code: shortcut essenziali

Questa è una **nota di esempio** collegata a `Code.exe` tramite `linked-process`.
Vedi anche [[demo-vscode-avanzate|shortcut avanzati]].

| Azione | Shortcut |
|---|---|
| Palette comandi | `Ctrl+Shift+P` |
| Apri file rapidamente | `Ctrl+P` |
| Terminale integrato | `` Ctrl+` `` |
| Commenta riga | `Ctrl+/` |
| Sposta riga su/giù | `Alt+↑` / `Alt+↓` |
